# Robinhood Chain Basis board

Live board: https://iixo3.github.io/rh-chain-board/

It compares each tokenized stock on Robinhood Chain with its real share price, and shows liquidity, mints and burns, and depegs. A fresh snapshot is published every 10 minutes.

Independent project, not affiliated with Robinhood. Nothing here is advice.

Built by iixo3. The code is published to show the work: you're welcome to read it, but it is not licensed for reuse.
