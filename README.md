# Robinhood Chain Basis board

**Paused for a rebuild since 5 November 2026.** Some of the prices and depeg records it showed were wrong, so they have been taken down.

Board address: https://iixo3.github.io/rh-chain-board/

It compares each tokenized stock on Robinhood Chain with its real share price, and shows liquidity, mints and burns, and depegs.

Independent project, not affiliated with Robinhood. Nothing here is advice.

Built by iixo3. The code is published to show the work: you're welcome to read it, but it is not licensed for reuse.
